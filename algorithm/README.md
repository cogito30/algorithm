# 알고리즘

## 1. 기본 자료구조와 시간 복잡도

- Big-O 표기법 이해 및 계산
- 배열(Array)과 리스트(List)
- 문자열(String) 처리 기본
- 해시(Hash)와 딕셔너리(Dictionary)

## 2. 선형 자료구조
- 스택(Stack)
- 큐(Queue)와 덱(Deque)
- 연결 리스트(Linked List)

## 3. 정렬과 탐색
- 기본 정렬 (버블, 선택, 삽입 정렬)
- 고급 정렬 (병합, 퀵 정렬)
- 이진 탐색(Binary Search)과 매개 변수 탐색(Parametric Search)

## 4. 완전 탐색과 백트래킹
- 완전 탐색 (Brute-Force)
- 재귀 함수(Recursion)의 이해
- 백트래킹(Backtracking) 기초 및 N-Queen 문제

## 5. 그래프 탐색 기본
- 그래프(Graph)의 표현 (인접 행렬, 인접 리스트)
- 깊이 우선 탐색 (DFS)
- 너비 우선 탐색 (BFS)

## 6. 동적 계획법 (DP) 기초
- 메모이제이션(Memoization)과 타뷸레이션(Tabulation)
- 점화식 세우기 (피보나치, 1로 만들기 등)

## 7. 그리디 알고리즘 & 투 포인터
- 그리디(Greedy) 알고리즘의 정당성 증명
- 투 포인터(Two Pointers)와 슬라이딩 윈도우(Sliding Window)

## 8. 최단 경로 알고리즘
- 다익스트라(Dijkstra) 알고리즘
- 플로이드-워셜(Floyd-Warshall) 알고리즘

## 9. 트리와 고급 그래프
- 트리(Tree) 순회 및 기본 연산
- 서로소 집합 (Disjoint Set / Union-Find)
- 최소 신장 트리 (MST - Kruskal, Prim)

## 10. 동적 계획법 (DP) 심화
- 배낭 문제 (Knapsack Problem)
- LCS (최장 공통 부분 수열)
- LIS (최장 증가 부분 수열)

## 11. 문자열 심화 및 기타 자료구조
- 트라이(Trie) 자료구조
- KMP 알고리즘
- 우선순위 큐와 힙(Heap) 심화

## 12. 심화 자료구조 및 실전 모의고사
- 세그먼트 트리(Segment Tree) 기초
- 누적 합(Prefix Sum)
